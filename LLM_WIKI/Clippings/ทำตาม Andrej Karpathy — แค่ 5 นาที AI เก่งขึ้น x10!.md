LLM Wiki คืออะไร ? เคยหงุดหงิดไหมครับที่ AI มักจะ "ความจำสั้น" พอเริ่มแชทใหม่ก็ลืมข้อมูลที่เราเคยสอนไปหมด?  
  
คลิปนี้ผมจะพาไปเจาะลึกเทคนิค "LLM Wiki" ที่กำลังเป็นไวรัลจาก Andrej Karpathy (อดีต Director of AI ของ Tesla และผู้ร่วมก่อตั้ง OpenAI) ที่จะช่วยให้คุณสร้าง "สมองที่สอง" (Second Brain) ให้ AI จำข้อมูลส่วนตัว ธุรกิจ หรือโปรเจกต์ของคุณได้แบบทบต้น แถมทำง่ายๆ โดยไม่ต้องพึ่งระบบ RAG (Retrieval-Augmented Generation) หรือ Vector Database ที่เขียนโค้ดยากและมีราคาแพง!  
  
เราจะมาแกะรอยแนวคิดจากทวีตของ Karpathy พร้อมสอนวิธี Setup ระบบนี้ด้วยตัวเองแบบจับมือทำ โดยใช้แค่ไฟล์ Text ธรรมดา โปรแกรม Obsidian และ Claude Code ครับ  
  
ถ้าคุณอยากประหยัดเวลา ลดต้นทุน Token และมี AI ผู้ช่วยที่เก่งขึ้นเรื่อยๆ ห้ามพลาดคลิปนี้ครับ! 👇

**6:01** · อะไรใหม่ขึ้นมาบ้างส่วน LC เนี่ยเราก็ สามารถดูได้ว่าเราสั่งคำสั่งหรือเราโยน อะไรให้กับ AI ในตอนไหนบ้างก็เก็บไว้ดู เป็นเหมือนกับ History นั่นแหละครับจะ เห็นได้ว่านอกจาก index กับlอกตัวเนี้ย ที่เหลือเนี่ย AI สร้างขึ้นมาเองหมดเลยนะ ครับไม่ว่าจะเป็น overview ตัวนี้หรือว่า จะเป็นพวกโฟลเดอรใน concept ต่างๆเนี่ยพอ

**6:19** · มันทำการ injest บทความหรือองค์ความรู้ ต่างๆเนี่ยมันก็จะสร้างมาเป็น concept เป็น\[เสียงกระแอม\]ต่างๆตรงเนี้ยซึ่งตรง นี้เราสามารถ customiz ให้เหมาะกับการใช้ งานของเราได้นะครับสุดท้ายอันนี้ก็คือ cross.md MD ก็คือเป็นเหมือนกับกดเป็น เหมือนกับ schema ที่ให้ AI ทำงานตามแบบ ที่เราต้องการซึ่งในตัวอย่างเนี่ยเราจะ ใช้เป็น CR กันจริงๆแล้วแก่นของไอเดีย ทั้งหมดเนี้ยเราแค่เก็บเป็น Markd ไฟล์ เป็นไฟลmdธรรมดาเนี่ยแะครับแต่ด้วยความ ที่ผมชอบเห็น visual ชอบเห็นความเชื่อม โยงเป็นกราฟสวยๆแบบเนี้ยผมเลยใช้ Obsidian

**6:43** · ซึ่งเป็นโนตแอปที่เราสามารถดาวน์โหลดได้ ฟรีร่วมกับ AI ที่ผมแนะนำให้ทุกคนลองมากๆ เลยในช่วงนี้นั่นก็คือ CL แล้วเราใช้ Cross Code นั่นเองมาเริ่มด้วยการ ดาวน์โหลด Obsidian ก่อนเลยแล้วกันครับ เราไปที่ Google แล้วก็เสิร์ชว่า Obsidian ตัวนี้นะครับ Obsidian.md MD กดเข้าไป

### ขั้นตอนการติดตั้ง Obsidian

**7:00** · ตรงนี้เราก็สามารถเลือกตัวนี้เราก็สามารถ เลือกดาวน์โหลดได้เลยนะครับว่าจะเป็น Windows เป็น Mac เป็นอะไรต่างๆเนาะพอ ดาวน์โหลดเสร็จแล้วเนี่ยให้เราทำการเข้า มาสร้าง wall ใหม่นะครับก็คือมาที่ซ้าย ล่างตรงนี้เรากดไปที่ Manage Walls เนาะ แล้วก็ Create New Wall ตรงนี้ได้เลย ผมจะใช้เป็น demo

**7:28** · แล้วตรงนี้ก็เลือก location นะครับว่า อยากให้ตัวโฟลเดอร์ตรงเนี้ยไปเก็บไว้ตรง ไหนเนาะ ทีนี้พอเราได้โฟลเดอร์สำหรับ Obsidian แล้วเนี่ยเราจะไปใช้ cross code กันต่อ ซึ่งการใช้งานเนี่ยจะเป็นการใช้ผ่านทาง แอปของ Cross เลยมาเลือก Cross Code ตรง นี้หรือว่าถ้าเป็นส่วนตัวผมเนี่ยก็จะใช้ ผ่าน Visual Studio Code เนาะสำหรับใคร ที่ไม่มีเนี่ยก็สามารถดาวน์โหลดได้เหมือน กับ Obsidian เมื่อกี้เลยเข้าไปที่ VS Code เนาะแล้วก็ตรงนี้เราก็เลือก

### ขั้นตอนการติดตั้ง VS Code และ Claude Code

**7:59** · ดาวน์โหลดได้เลยว่าเราใช้เครื่องอะไรอยู่ พอเปิด VS Code ขึ้นมาแล้วเนี่ยเราก็กด Open ตรงนี้นะครับแล้วก็ไปเลือกโฟลเดอร์ ที่เราสร้าง W ของ Obsidian เมื่อกี้ไว้ อย่างอันนี้ของผมเป็น Demo Wall ตรงนี้ เนาะกด Open เปิดขึ้นมาเสร็จแล้ว VS Code เขาจะมี เป็น view in agent นะครับแต่ว่าเราจะ ไม่ได้ใช้เราจะมาใช้เป็น cross code Extension กันสำหรับใครที่ไม่มีเนี่ยก็ กดตรงนี้แล้วก็เสิร์ชว่า cross code

**8:26** · ตรงนี้เนาะแล้วก็กด install extension ไปพอ install เรียบร้อยแล้วเนี่ยก็จะมี โลโก้ของ cross มาโผลดตรงนี้ให้เรากดก็จะ เป็นการเปิดหน้าต่าง cross code ขึ้นมา ทีนี้หลักการในการทำเนี่ยง่ายมากๆเลยครับ เราจะไปที่ twet ของ carty กันแล้วกดไป ที่ลิงกตรงนี้นะครับตรงนี้เนี่ยเขาแปะไว้ ให้เราเรียบร้อยและ เราก็ก๊อปมาเลย
