# DaVinci Resolve MCP (viaSocket)

> viaSocket MCP Server for DaVinci Resolve — a commercial MCP platform connecting DaVinci Resolve to AI tools.

## Overview

viaSocket MCP Server lets you easily connect DaVinci Resolve actions with AI tools like ChatGPT, Claude, and Cursor, all with built-in authentication.

### 3 Easy Steps

1. **Get Your MCP Endpoint** — instantly get a unique, secure URL
2. **Choose Your Actions** — configure actions your AI assistant can perform
3. **Connect Your AI Assistant** — connect with the MCP endpoint for instant task execution

### Key Features

- Free for lifetime under a fair usage policy without rate limits
- Enterprise plans available
- Connects to 1,000+ apps
- Built-in authentication
- No need to manage integrations
