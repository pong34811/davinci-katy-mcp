# DaVinci Resolve AI Control — Automate Video Editing

> Short listing on mcpmarket.com for the DaVinci Resolve MCP server. Consolidated into [[samuelgursky davinci-resolve-mcp MCP server|primary source]].

## Summary

This tool acts as a Model Context Protocol (MCP) server, bridging the gap between AI assistants like Claude and DaVinci Resolve. By leveraging the MCP protocol, it allows direct interaction and control over DaVinci Resolve's features: project management, timeline manipulation, media management, Fusion composition creation, and execution of Python code within DaVinci Resolve.

### Key Features

1. Connect Claude AI to DaVinci Resolve via the MCP protocol
2. Manage DaVinci Resolve projects, timelines, and media pools
3. Create and modify Fusion compositions
