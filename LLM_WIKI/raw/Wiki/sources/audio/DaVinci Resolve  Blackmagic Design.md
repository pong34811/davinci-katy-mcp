# DaVinci Resolve | Blackmagic Design

> Official product page for DaVinci Resolve 21 — the world's only solution combining editing, color, VFX, motion graphics, and audio post production.

## Overview

DaVinci Resolve is the world's only solution that combines editing, color correction, visual effects, motion graphics, audio post production and photo editing all in one software tool. Its elegant, modern interface is fast to learn yet powerful for professionals.

## Pages

- **Edit** — the world's most advanced professional NLE
- **Cut** — designed for fast turnaround
- **Color** — Hollywood's most advanced color corrector
- **Fusion** — cinematic visual effects and motion graphics
- **Fairlight** — professional audio post production (2,000 tracks, realtime effects)
- **Media and Delivery** — import, manage, and deliver final projects

## Key Features

- **DaVinci AI Neural Engine** — facial recognition, object detection, smart reframing, speed warp retiming, super scale, auto color
- **Resolve FX** — 100+ GPU-accelerated effects
- **Multi-user collaboration** — project libraries for real-time local and remote collaboration via Blackmagic Cloud
- **Photo page** — Hollywood color tools for still photos

## Versions

- **DaVinci Resolve** — free, up to Ultra HD 3840x2160 at 60fps
- **DaVinci Resolve Studio** — $295, adds Neural Engine, 10-bit at 120fps, advanced features
