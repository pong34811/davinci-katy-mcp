# Source: samuelgursky/davinci-resolve-mcp MCP Server

Primary source for the `davinci-resolve-mcp` project — the open-source MCP server that connects AI assistants to DaVinci Resolve via the official Python Scripting API.

## Key Facts

- **Project:** [samuelgursky/davinci-resolve-mcp](https://github.com/samuelgursky/davinci-resolve-mcp)
- **MCP Tools:** 36 compound / 353 granular (live server)
- **API Coverage:** 361/361 (100%)
- **Live Test Pass Rate:** 338/338 (100%)
- **Server Modes:** Compound (default) and Full/Granular
- **Free Edition:** In-app bridge via `Workspace ▸ Scripts > resolve_bridge`
- **Advanced MCP:** `davinci-resolve-advanced-mcp` (18 offline tools)
- **Key API Ceiling:** Color nodes, Fusion, Fairlight not exposed to scripting
